Argument registers on macOS x86-64 syscall
For a syscall instruction, the number goes in:
`rax`
example:
mov rax, 0x2000004
syscall

Arguments generally go in:
`rdi, rsi, rdx, r10, r8, r9`

Return value comes back in:
rax

A C library call uses a normal function call:
extern _printf
call _printf
