x86 registers:

rdi : 8 bytes, destination index
rsi : 8 bytes, source index

rax : 8 bytes (64 bits), general purpose

rsp : 8 bytes, stack pointer, holds address of the top of stack (stack grows down)
rbp : 8 bytes, stack base pointer

edi ; lower 4 bytes (32 bits) of rdi
esi ; lower 4 bytes (32 bits) of rsi

di  ; lower 2 bytes (16 bit) of rdi
si  ; lower 2 bytes (16 bit) of rsi


rax :  64 bits  ; signed / unsigned long ( r = really extended)
eax :  32 bits  ; signed / unsigned int  ( e = extended)
ax  :  16 bits  ; signed / unsigned short
ah  :  ax high byte ; signed / unsigned byte
al  :  ax low byte  ; signed / unsigned byte

8 byte (64 bit) registers:
AX,   BX,  CX,  DX
EAX, EBX, ECX, EDX,
RAX, RBX, RCX, RDX

RAX EAX AX AH AL - Mathematical operations, i.e. division, multiplication
RCX ECX CX CH CL - counting, loops, bit shifting
RDX EDS DX DH DL - data i/o in and out instructions (kernel level) , writing to hardware
RBX EBX BX BH BL - expects a calling convention where we push and pop

Stack pointer
RSP (8 bytes), ESP (4 bytes), and SP (16 bytes). No SH nor SL
Pointes to anywhere in memory
push instruction called decrements by one "word"
pop increments by one "word"

RBP (8 bytes), EBP (4 bytes), BP (2 bytes)
Points to old stack pointer
can also relatively address on the stack

RDI (8 bytes), EDI (4 bytes) DI (2 bytes)
used for string or data copying instructions for output

RSI (8 bytes), ESI (4 bytes), SI (2 bytes)
used for string or data copying instructions for input

MXCSR Register: Control and Status register
    a 32-bit control and status register used for Streaming SIMD Extensions (SSE)
    and AVX floating-point operations in x86/x64
    control flags for floating point operations, like rounding

MXCSR.IM : if 0, floating-point invalid operation exceptions are unmasked
MXCSR.RC : Controls rounding modes (0 = nearest, 1 = down, 2 = up, 3 = truncate).

size modifiers:
qword   : quad word, 8 bytes (64 bits)
dword   : double word, 4 bytes (32 bits)
word    : 2 bytes (16 bits)
byte    : 1 byte (8 bits)


Brackets [] indicate a dereference operation
$ means "current address"

Operations:
********************************
add : adds the operands and places the result in the first register
    When adding two registers, they must be the same width
    add rdi, rsi   ; add the values in rdi and rsi together and place result in rdi
    add rdi, qword ptr [rsp - 8]  ; add rdi to the value at the computed address, store result in rdi

cmp : compare two values by subtracting the second op from the first. The result of comparison written to a flag in cpu
    cmp op1, op2    ;  op1 - op2
                    ;  if equal, expression is 0, zero flag is set
                    ;  if op2 > op1, expression is negative, sign bit is set
                    ;
    cmp rdi, rsi    ;

cmps: compare string operands:
        compare two string values at locations in rdi and rsi. Advance each after the compare by the data size
        cmpsb, cmpsw, cmpsd, cmpsq

CWD/CDQ/CQO : convert word to double word, convert double word to quad word, convert quad word to octo word
    Doubles the size of the operand in register AX, EAX, or RAX and
    stores the result in registers DX:AX, EDX:EAX, or RDX:RAX, respectively


dup:    MASM directive, "duplicate"
    e.g.
        Val8 db ?         ; Val8 is a single uninitialized data byte
        PadA db 7 dup (?) ; PadA is a data byte, duplicated 7 times. `?` means it has no initial value

inc : increment register
    inc rsi ; adds 1 to the value in rsi and stores in rsi

jcc: jump on condition code

jg  : jump if greater. evaluates result of last cmp, if first operand was > second operand, makes the jump
    jg .greater ; jump to label .greater

jmp : unconditional jump to a label

lea : load effective address
    lea rdi, [rsp-8]    ; calculate a memory address as offset from rsp
                        ; copy that address into register rdi


leave :  restores rsp and rbp. copies rbp into rsp, pop rbp.

lods:   load string data
lodsb, lodsw,lodsd, lodsq

    ; lodsb: load byte at address (R)SI into AL (loads [rsi] into rax)
    ; after the load, increments/decrements the value in rsi by the size of the operand,
    ; uses EFLAGS.DF 0 == increment, 1 == decrement. Default on mac/System V is 0


mov : copies data. only 1 operand can be memory.
    ;  mov instruction is the only instruction that supports 64-bit immediate operands.
    mov rdi, 2     ; move immediate value 2 into the rdi register
    mov rdi, 0xfedc_ ; move immediate value (address) into rdi register
    mov qword ptr [rsp - 8], rsi  ; [rsp - 8] is a computed expression
                                  ; `qword ptr` dereferences the int expression value to obtain an address
                                  ; copy value from rsi to the evaluated memory address
movs: movsb, movsw, movsd, movsq
    move string operands specified with the second operand (mem source operand in [rsi])
    to the location specified with the first operand (mem destination operand in [rdi]).
    after the move, both registers are incremented by data size

mul : unsigned int multiply.
    ; multiplies rax and the given operand, stores in rdx:rax.
    ; Implicitly uses rax as an operand, places result in rdx:rax
    ; multiplying two n-bit numbers results in a max product size of 2n
    mul rbx ; equivalent in C to rdx:rax = rax * rbx. Result stored in rax, overflow in rdx


pop : pop value at top of stack into the given register
    pop rsi     ;  copies 8 bytes from top of stack into rsi (low address to high address)
                ;  stack pointer rsp is incremented by 8 bytes

popfq: pop EFLAGS from stack into RFLAGS


push: PUSHF/PUSHFD/PUSHFQ — Push EFLAGS Register Onto the Stack

push : push register value onto stack
    push rdi  ; push value of rdi register to top of stack, given by rsp stack pointer
              ; rdi is 8 byte register, so 8 bytes are written to stack.
              ; LE means lsb of register value is written first.
              ; rsp stack pointer is also decremented by 8 bytes

rep:
    REP/REPE/REPZ/REPNE/REPNZ — Repeat String Operation Prefix
    works with rcx to count down/up according to EFLAGS.DF


ret : return from subroutine. Current subroutine must have been invoked with a call instruction
    ret

setcc : set byte on condition code. set the destination byte to 1 if condition is met, 0 otherwise
sete  : set byte if equal.
setp  : set byte if parity bit is set

std:    set direction flag, RFLAGS.DF to 1

stos:
    STOS/STOSB/STOSW/STOSD/STOSQ — Store String
    Store RAX at address in RDI

vcmpss, vcmpsd : compare two scalar floats
    Doesn't set any bits in RFLAGS. Instead, sets the destination to all 0s or 1s according to predicate evaluation

vcomiss, vcomisd : compare two scalar floats.
    Similar to vucomi[s|d], except throws exception (if enabled) if an operand is SNaNs or QNaNs

vucomiss, vucomisd : unordered compare of scalar floats
    Sets RFLAGS.ZF, PF, CF
    unordered if all set, > if all unset, < if CF set, equal if ZF set
    check PF for unordered result
    throws exception (if enabled) for SNaNs but not QNaNs

xor : logical exclusive or
    Store the result of two registers or memory locations in the destination
    fastest way to clear a register is to xor it with itself.
    e.g.: xor rax, rax  ; rax := 0



Jumping : jcc = jump on condition code
    cmp op1, op2

    je  label   ; op1 == op2    ; is zero bit set?
    jne label   ; op1 != op2

    jl  label   ; op1 <  op2
    jle label   ; op1 <= op2
    jg  label   ; op1 >  op2    ; is sign bit set?
    jge label   ; op1 >= op2

    // unsigned b = "below", a = "above"

    jb  label   ; op1 <  op2
    jbe label   ; op1 <= op2
    ja  label   ; op1 >  op2
    jae label   ; op1 >= op2

Looping:
    mov rcx, 1
    mov rax, 0
 .for
    cmp rcx, 3
    je  .endfor
    add rax, rcx
    inc rcx
    jmp .for
 .endfor

memory addressing:
Up to up to four separate components are needed to specify the location of an operand in memory.
The four components include a constant displacement value, a base register, an index register, and a scale factor.

Effective Address = BaseReg + IndexReg * ScaleFactor + Disp
    ScaleFactor = 1, 2, 4, or 8
    Disp        = 8-, 16-, or 32-bit signed offset

see table 1.6 in "X86-64 Core architecture"
